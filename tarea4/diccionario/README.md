# Diccionario de Datos Físico Comparativo

En esta sección se adjunta el documento correspondiente al diccionario de datos físico de la Red Social Estudiantil Pascualina.

**Nota importante:** En esta carpeta se encuentra **un solo archivo PDF** debido a que se unificaron los tres requerimientos de la guía en una sola **Tabla Comparativa**. En ese único cuadro se presentan en paralelo las equivalencias de tipos de datos, llaves e integridad para **PostgreSQL 17**, **MySQL 9.0** y **SQLite 3**, evitando duplicidad de documentos y facilitando el análisis comparativo para la revisión.
